# Simple To-Do List

A beginner-friendly task manager made with HTML, CSS and JavaScript.

## Features
- Add tasks, mark them complete, and delete them
- Filter by All, Active and Completed
- Clear all completed tasks
- Save tasks in browser localStorage
- Simple responsive layout

## Run
1. Extract this folder.
2. Open it in VS Code.
3. Open `index.html` in a browser, or use Live Server.
4. Add tasks and refresh the page to test saved data.

## Files
- `index.html`: page structure
- `style.css`: design and responsive rules
- `script.js`: task logic, events and localStorage
- `VIVA-GUIDE.md`: walkthrough and sample viva questions

Note: Tasks are saved in the current browser only. There is no backend or synchronisation between devices.
